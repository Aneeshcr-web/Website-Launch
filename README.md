# StreetCast website

Static HTML/CSS website for Vercel.

## Vercel settings

- Framework Preset: **Other**
- Root Directory: **./**
- Build Command: **leave blank**
- Output Directory: **leave blank/default**
- Install Command: **leave blank**

The homepage is `index.html` at the repository root.

## Repository structure

```text
/
├── index.html
├── vercel.json
└── assets/
    ├── image-01.png
    ├── image-02.webp
    └── ...
```

No Node.js, npm install, or build command is required.
